# Medieval visual refresh

The UI now combines painted environment art with scalable illustrated items and
bestiary portraits. The four environment scenes cover shores, woodland, the forge,
and a snowy fortress, with atmospheric treatments for marshes and deepwater areas.
One compressed WebP sheet is shared across skill, combat, and dungeon screens.

Loot uses recognizable silhouettes: fish, plated food, swords, armor, shields,
boots, ore, bars, runestones, logs, crops, farm animals, and other resources.
Equipment materials change their color palette. The navigation retains restrained
brass symbols so the more colorful loot stands out.

Panels use subtle aged stone and wood patterns, warmer brass accents, serif headings,
and softer green action buttons. The desktop Adventure Journal fills the right column
with supplies, upcoming unlocks, and recent milestones. It hides on smaller screens.

Live level-ups, quests, and rare loot trigger short milestone cards. Rare skill drops
also enter the activity log. Reward sounds default to off and can be enabled in
Settings; the preference persists in the browser. Effects respect reduced motion.
Historical offline activity does not trigger live celebration cards when an offline
summary is shown.

Validation covers build/type checks, lint, desktop/phone browser previews, and the
14 browser regressions, including sound preference persistence and a rare-loot discovery
through the real fishing controls. The existing save and offline-progress checks remain.
